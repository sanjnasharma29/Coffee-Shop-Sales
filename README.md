# Coffee-Shop-Sales
# Data Analytics Project

## Overview

This project demonstrates an end-to-end **data analytics workflow** using an Excel dataset. The project covers data loading, exploratory data analysis (EDA), data cleaning, pivot table creation, and dashboard development to transform raw data into meaningful business insights.

## Dataset

The project uses an **Excel dataset** containing structured business data.

The dataset was analyzed to:

* Understand the structure and quality of the data
* Identify trends and patterns
* Clean and prepare the data for analysis
* Create meaningful summaries using pivot tables
* Build an interactive dashboard for visualization

> **Dataset:** Coffee Shop Sales
> **Fields:** Transaction ID, Transaction Date, Transaction Time, Transaction Quantity, Store ID, Store Location, Product ID, Unit Price, Product Category, Product Type, Product Detail.

## Tools & Technologies

* **Microsoft Excel** – Data loading, cleaning, analysis, pivot tables, and dashboard creation
* **Excel Pivot Tables** – Data aggregation and summarization
* **Excel Charts** – Data visualization
* **Excel Functions** – Data cleaning and transformation

## Project Steps

### 1. Load Dataset

* Imported the Excel dataset into the analysis environment.
* Reviewed the available columns and data types.
* Checked the overall structure of the dataset.

### 2. Exploratory Data Analysis (EDA)

* Examined key variables and their distributions.
* Identified trends, patterns, and potential outliers.
* Analyzed important metrics and categories.
* Checked for missing or inconsistent values.

### 3. Data Cleaning

* Removed duplicate records where required.
* Handled missing and invalid values.
* Standardized inconsistent formats.
* Corrected data types and formatting.
* Prepared the dataset for analysis.

### 4. Pivot Tables

Created pivot tables to summarize the cleaned data and answer key business questions, such as:

* Category-wise performance
* Time-based trends
* Regional or segment-wise analysis
* Sales/revenue or other key metric comparisons

### 5. Dashboard

Developed an Excel dashboard to present the most important insights in a clear and user-friendly format.

The dashboard includes:

* Key Performance Indicators (KPIs)
* Charts and visualizations
* Interactive filters/slicers where applicable
* Trend analysis
* Category and segment comparisons
